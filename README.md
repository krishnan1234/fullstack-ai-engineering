# Full-Stack AI Engineering: The 10-Month Pivot

## 🎯 Goal
To bridge the gap between core software engineering and Artificial Intelligence, targeting a high-performance role in a Tier-1 MNC by 2027.

## 🛠 Tech Stack
- **Languages:** Java 21 (Core/DSA), Python (AI/ML).
- **Backend:** Spring Boot, PostgreSQL, Redis.
- **AI/ML:** PyTorch, Scikit-Learn, Pandas.
- **Cloud/Ops:** AWS (EC2, S3, SageMaker), Docker, Kubernetes.

## 🗓 The Discipline
- **Weekdays (1hr):** 1-2 LeetCode problems (Java) to maintain problem-solving intuition.
- **Weekends (15-16hrs):** Intensive sprints covering System Design, Cloud Architecture, and AI Model Development.

## 📂 Repository Structure
- `/daily-dsa-java`: Daily algorithmic practice.
- `/weekend-projects`: Full-scale implementations and service deployments.
- `/system-design`: Architecture diagrams and notes on scalability.
